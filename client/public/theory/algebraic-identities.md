# Αλγεβρικές ταυτότητες

Η επιμεριστική ιδιότητα δίνει α(b + c) = ab + ac.

Βασικές ταυτότητες: (a + b)² = a² + 2ab + b², (a − b)² = a² − 2ab + b² και (a + b)(a − b) = a² − b².

Μπορούμε να αναπτύξουμε ένα γινόμενο ή να παραγοντοποιήσουμε ένα πολυώνυμο αναγνωρίζοντας την αντίστροφη μορφή της ταυτότητας.

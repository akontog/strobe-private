1. Άλγεβρα

Σειρά από input boxes για συμπλήρωση.

Αριστερά μπορεί να υπάρχει:

* εικονίδιο,
* MathJax έκφραση,
* μαθηματική οδηγία.

Δεξιά μπορεί να υπάρχει στατικό γράφημα ή άλλη οπτική αναπαράσταση.

Το εργαλείο χρησιμοποιείται κυρίως για:

* συμπλήρωση τύπων,
* ανάπτυξη παραστάσεων,
* ενδιάμεσα βήματα,
* υπολογισμό,
* αναγνώριση παραμέτρων.

2. Drag and Drop Matching

Οι μαθητές μεταφέρουν αντικείμενα και τα τοποθετούν στην κατάλληλη περιοχή.

3. Collaborative GeoGebra

Συνεργατικό GeoGebra που λειτουργεί real-time.

Μπορεί να διαθέτει:

* προφορτωμένα αντικείμενα,
* σημεία,
* ευθείες,
* γεωμετρικά σχήματα,
* sliders,
* μεταβλητές,
* συγκεκριμένα αντικείμενα που μπορούν να χειριστούν οι μαθητές.

Να χρησιμοποιείται κυρίως για **διερεύνηση και οπτική κατανόηση**.


4. Embodied / Camera

Χρήση camera tracking και persistent ID.

Οι μαθητές μπορούν να:

* μετακινούνται στον χώρο,
* σχηματίζουν ομάδες,
* μπαίνουν σε χωρικές ζώνες,
* αντιστοιχίζουν αντικείμενα,
* αναπαριστούν μαθηματικά αντικείμενα.

Το σύστημα πρέπει να γνωρίζει:

- studentId
- x
- y
- zoneId
- timestamp

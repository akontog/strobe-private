# 1. Μονώνυμα

## 1.1 Βασικές έννοιες μονωνύμων

### Στόχος

Οι μαθητές να αναγνωρίζουν τα βασικά στοιχεία ενός μονωνύμου:

- συντελεστής
- μεταβλητές
- εκθέτες
- βαθμός ως προς κάθε μεταβλητή
- συνολικός βαθμός

### Παράδειγμα

$3x^4y^2$

Οι μαθητές πρέπει να αναγνωρίσουν:

- συντελεστής: 3
- εκθέτης του x: 4
- εκθέτης του y: 2
- βαθμός ως προς x: 4
- βαθμός ως προς y: 2
- συνολικός βαθμός: 6

### Συνεργατική διάσταση

Κάθε μαθητής της ομάδας αναλαμβάνει διαφορετικό χαρακτηριστικό του μονωνύμου.

Μαθητής Α → συντελεστής  
Μαθητής Β → εκθέτης του x  
Μαθητής Γ → εκθέτης του y  
Μαθητής Δ → συνολικός βαθμός

Η ομάδα πρέπει να ολοκληρώσει σωστά ολόκληρη την αναπαράσταση.

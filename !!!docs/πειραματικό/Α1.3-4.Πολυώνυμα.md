# Πολυώνυμα και μονώνυμα

## Εισαγωγή

Το εργαστήριο αυτό έχει σχεδιαστεί για να βοηθήσει τους μαθητές να κατανοήσουν τα βασικά χαρακτηριστικά των μονωνύμων και των πολυωνύμων, καθώς και τις πράξεις που μπορούν να γίνουν πάνω τους. Κάθε δραστηριότητα εστιάζει σε διαφορετικό επίπεδο κατανόησης: αναγνώριση, ομοιότητα όρων, αναγωγή, πρόσθεση, αφαίρεση και πολλαπλασιασμό.

---

# 1. Μονώνυμα

## 1.1 Βασικές έννοιες μονωνύμων

### Στόχος

Οι μαθητές να αναγνωρίζουν τα βασικά στοιχεία ενός μονωνύμου:

- τον συντελεστή
- τον εκθέτη του $x$
- τον εκθέτη του $y$
- τον βαθμό ως προς $x$
- τον βαθμό ως προς $y$
- το συνολικό βαθμό του μονωνύμου

### Παράδειγμα

$3x^4y^2$

- Συντελεστής: $3$
- Βαθμός ως προς $x$: $4$
- Βαθμός ως προς $y$: $2$
- Συνολικός βαθμός: $4+2=6$

### Παραδείγματα δραστηριότητας

1. $3x^4y^2$
   - Συντελεστής: $3$
   - $	ext{deg}_x = 4$
   - $	ext{deg}_y = 2$
   - $	ext{deg}_{xy} = 6$

2. $-5x^2y^3$
   - Συντελεστής: $-5$
   - $	ext{deg}_x = 2$
   - $	ext{deg}_y = 3$
   - $	ext{deg}_{xy} = 5$

3. $7x^3y$
   - Συντελεστής: $7$
   - $	ext{deg}_x = 3$
   - $	ext{deg}_y = 1$
   - $	ext{deg}_{xy} = 4$

---

## 1.2 Πράξεις με μονώνυμα (πρόσθεση-αφαίρεση)

### Στόχος

Οι μαθητές να αναγνωρίζουν όμοια μονώνυμα και να τα συνδυάζουν με πρόσθεση ή αφαίρεση. Η βασική προϋπόθεση είναι να έχουν το ίδιο μέρος μεταβλητών και τους ίδιους εκθέτες.

### Κανόνας

Μόνο όμοια μονώνυμα μπορούν να προστεθούν ή να αφαιρεθούν:

$ax^m y^n + bx^m y^n = (a+b)x^m y^n$

### Παραδείγματα δραστηριότητας

1. $2x^2y + 3x^2y = 5x^2y$
2. $4xy^3 - 2xy^3 = 2xy^3$
3. $7x^3y^2 + 3x^3y^2 - x^3y^2 = 9x^3y^2$

### Σημείωση

Το κοινό μέρος $x^m y^n$ παραμένει ίδιο και μόνο οι συντελεστές αθροίζονται ή αφαιρούνται.

---

## 1.3 Πράξεις με μονώνυμα (πολλαπλασιασμός)

### Στόχος

Οι μαθητές να πολλαπλασιάζουν μονώνυμα εφαρμόζοντας τους κανόνες των εκθετών:

- πολλαπλασιάζονται οι συντελεστές
- προστίθενται οι εκθέτες του ίδιου γράμματος

### Κανόνας

$ax^m y^n \cdot bx^p y^q = (a\cdot b)x^{m+p}y^{n+q}$

### Παραδείγματα δραστηριότητας

1. $3x^2y \cdot 5x^3y^2 = 15x^5y^3$
2. $-2x^3y \cdot 4xy = -8x^4y^2$
3. $6x^2y^3 \cdot 3x^4y = 18x^6y^4$

---

# 2. Πολυώνυμα

## 2.1 Βασικές έννοιες πολυωνύμων

### Στόχος

Οι μαθητές να αναγνωρίζουν τα βασικά χαρακτηριστικά ενός πολυωνύμου και να υπολογίζουν:

- τον βαθμό ως προς $x$
- τον βαθμό ως προς $y$
- το συνολικό βαθμό

### Παραδείγματα δραστηριότητας

1. $3x^2y + 5xy^3 - 7x^4 + 2y^2$
   - $	ext{deg}_x = 4$
   - $	ext{deg}_y = 3$
   - $	ext{deg}_{xy} = 7$

2. $2x^3y^2 - 4x^2y + 3x^5$
   - $	ext{deg}_x = 5$
   - $	ext{deg}_y = 2$
   - $	ext{deg}_{xy} = 7$

3. $x^4y - 5xy^2 + 3x^2y^3$
   - $	ext{deg}_x = 4$
   - $	ext{deg}_y = 3$
   - $	ext{deg}_{xy} = 7$

### Σημείωση

Στο πολυώνυμο ο βαθμός του όρου με τον μεγαλύτερο συνολικό εκθέτη καθορίζει τον βαθμό του πολυωνύμου.

---

## 2.2 Αναγωγή ομοίων όρων

### Στόχος

Οι μαθητές να συνδυάζουν όμοιους όρους και να απλοποιούν το πολυώνυμο.

### Κανόνας

Προσθέτουμε ή αφαιρούμε μόνο τους συντελεστές των όμοιων όρων:

$3x^2y + 5x^2y - 2x^2y = 6x^2y$

### Παραδείγματα δραστηριότητας

1. $3x^2y + 5x^2y - 2x^2y = 6x^2y$
2. $4xy^3 + 2xy^3 - 3xy^3 = 3xy^3$
3. $7x^3y^2 - 2x^3y^2 + 4x^3y^2 = 9x^3y^2$

### Σημείωση

Η αναγωγή ομοίων όρων είναι η διαδικασία της απλοποίησης ενός πολυωνύμου σε μικρότερο πλήθος όρων.

---

## 2.3 Πράξεις με πολυώνυμα (πρόσθεση-αφαίρεση)

### Στόχος

Οι μαθητές να προσθέτουν και να αφαιρούν πολυώνυμα, να αναγνωρίζουν τους όμοιους όρους και να τους συνδυάζουν σωστά.

### Παραδείγματα δραστηριότητας

1. $(3x^2y + 5xy^2) + (2x^2y - 3xy^2)$
   - Όμοιοι όροι: $3x^2y + 2x^2y = 5x^2y$
   - Όμοιοι όροι: $5xy^2 - 3xy^2 = 2xy^2$
   - Αποτέλεσμα: $5x^2y + 2xy^2$

2. $(7x^3 - 2x^2y) + (4x^3 + 5x^2y)$
   - Όμοιοι όροι: $7x^3 + 4x^3 = 11x^3$
   - Όμοιοι όροι: $-2x^2y + 5x^2y = 3x^2y$
   - Αποτέλεσμα: $11x^3 + 3x^2y$

3. $(6x^2y^2 - 3xy + 2x) - (2x^2y^2 - xy + x)$
   - Αφαιρούμε κάθε όρο του δεύτερου πολυωνύμου
   - $6x^2y^2 - 2x^2y^2 = 4x^2y^2$
   - $-3xy - (-xy) = -2xy$
   - $2x - x = x$
   - Αποτέλεσμα: $4x^2y^2 - 2xy + x$

### Σημείωση

Σε αυτή τη δραστηριότητα υπάρχουν και περιπτώσεις όπου οι όμοιοι όροι δεν είναι ακριβώς ίδιοι σε όλες τις μεταβλητές, οπότε η αναγωγή γίνεται μόνο στα κατάλληλα ζεύγη όρων.

---

## 2.4 Πράξεις με πολυώνυμα (πολλαπλασιασμός)

### Στόχος

Οι μαθητές να εφαρμόζουν την επιμεριστική ιδιότητα για να πολλαπλασιάζουν δύο πολυώνυμα μεταξύ τους.

### Παραδείγματα δραστηριότητας

1. $(2x + 3y)(x + y)$
   - $2x\cdot x = 2x^2$
   - $2x\cdot y = 2xy$
   - $3y\cdot x = 3xy$
   - $3y\cdot y = 3y^2$
   - Αποτέλεσμα: $2x^2 + 5xy + 3y^2$

2. $(x + 2y)(3x - y)$
   - $x\cdot 3x = 3x^2$
   - $x\cdot (-y) = -xy$
   - $2y\cdot 3x = 6xy$
   - $2y\cdot (-y) = -2y^2$
   - Αποτέλεσμα: $3x^2 + 5xy - 2y^2$

3. $(2x - y)(x + 4y)$
   - $2x\cdot x = 2x^2$
   - $2x\cdot 4y = 8xy$
   - $-y\cdot x = -xy$
   - $-y\cdot 4y = -4y^2$
   - Αποτέλεσμα: $2x^2 + 7xy - 4y^2$

---

# Σύνοψη

Οι δραστηριότητες του εργαστηρίου καλύπτουν τρία βασικά επίπεδα:

1. αναγνώριση των στοιχείων ενός μονωνύμου και πολυωνύμου
2. συνδυασμός και απλοποίηση όμοιων όρων
3. πράξεις με μονώνυμα και πολυώνυμα (πρόσθεση, αφαίρεση, πολλαπλασιασμός)

Η αλυσίδα αυτή βοηθά τους μαθητές να προχωρήσουν από την κατανόηση του απλού μονομάτη σε πιο σύνθετες αλγεβρικές μορφές με σαφή λογική και οργάνωση.

# Α3.2 – Α3.3 Γραμμικά Συστήματα

## Γραφική και αλγεβρική επίλυση – 3 διδακτικές ώρες

## 1. Στόχος

Να σχεδιαστεί μια **συνεργατική και ενσώματη εκπαιδευτική δραστηριότητα** για τη διδασκαλία των:

* **Α3.2. Γραμμικό σύστημα και γραφική επίλυση**
* **Α3.3. Αλγεβρική επίλυση γραμμικού συστήματος**

συνολικής διάρκειας **3 ωρών**.

Η δραστηριότητα πρέπει να συνδέει:

1. τη γραφική αναπαράσταση ενός γραμμικού συστήματος,
2. την έννοια της λύσης ως σημείου τομής,
3. τις διαφορετικές περιπτώσεις λύσεων,
4. την αλγεβρική επίλυση,
5. την επαλήθευση της αλγεβρικής λύσης μέσω της γραφικής αναπαράστασης.


# 2. Τεχνολογικό πλαίσιο

Η δραστηριότητα θα ενσωματωθεί σε υπάρχον **Node.js + React συνεργατικό εκπαιδευτικό περιβάλλον**.

Το σύστημα διαθέτει ήδη:

* συνεργατική λειτουργία πολλών χρηστών,
* React frontend,
* Node.js backend,
* συνεργατικό GeoGebra
* camera-based tracking,
* persistent ID για την αναγνώριση των μαθητών,
* δυνατότητα real-time ενημέρωσης όλων των χρηστών.

Η νέα δραστηριότητα πρέπει να σχεδιαστεί ώστε να μπορεί να λειτουργήσει:

* ψηφιακά με mouse/touch (geogebra),
* συνεργατικά,
* ενσώματα με camera tracking.


# 3. Διδακτική ενότητα Α3.2

## Γραμμικό σύστημα και γραφική επίλυση

### 3.1 Αναπαράσταση δύο εξισώσεων

Να δίνεται ένα σύστημα όπως:

$$
\begin{cases}
y=2x-1\\
y=-x+5
\end{cases}
$$

και να εμφανίζονται οι δύο ευθείες σε κοινό καρτεσιανό επίπεδο.

Ο μαθητής πρέπει να αντιληφθεί ότι η λύση του συστήματος είναι το σημείο που ικανοποιεί **και τις δύο εξισώσεις**.

---

# 4. Ενσώματη αναπαράσταση καρτεσιανού επιπέδου

Ο φυσικός χώρος της τάξης μπορεί να χρησιμοποιείται ως καρτεσιανό επίπεδο.

Οι μαθητές μετακινούνται στον χώρο και η κάμερα εντοπίζει:

```text
studentId
x
y
```

όπου:

* `studentId` = persistent ID μαθητή,
* `x` = θέση στον οριζόντιο άξονα,
* `y` = θέση στον κατακόρυφο άξονα.

Το σύστημα πρέπει να μπορεί να αντιστοιχίζει τη φυσική θέση του μαθητή σε μαθηματικές συντεταγμένες.

Παράδειγμα:

```text
                    y
                    ↑
                    │
                    │       ● Student A
                    │
───────────────┼────┼──────────────→ x
                    │
                    │
```

Ο μαθητής μπορεί να μετακινηθεί μέχρι να βρεθεί στο σημείο λύσης.

---

# 5. Δραστηριότητα «Βρες το σημείο τομής»

Δίνεται:

$$
\begin{cases}
y=2x-1\\
y=-x+5
\end{cases}
$$

Οι μαθητές πρέπει να εντοπίσουν γραφικά το σημείο τομής.

Η σωστή λύση είναι:

$$
(2,3)
$$

Το σύστημα μπορεί να αναγνωρίζει την απόσταση του μαθητή από το σημείο:

$$
(2,3)
$$

και να παρέχει feedback.

### Στόχος

Ο μαθητής να κατανοήσει ότι:

> Η λύση ενός γραμμικού συστήματος είναι το κοινό σημείο των δύο ευθειών.

---

# 6. Οι τρεις περιπτώσεις γραμμικού συστήματος

Να δημιουργηθούν δραστηριότητες για:

## 6.1 Μία λύση

Οι δύο ευθείες τέμνονται σε ένα σημείο.

```text
\ /
 ●
/ \
```

## 6.2 Καμία λύση

Οι δύο ευθείες είναι παράλληλες.

```text
────────────

────────────
```

## 6.3 Άπειρες λύσεις

Οι δύο εξισώσεις παριστάνουν την ίδια ευθεία.

```text
════════════
```

Οι μαθητές πρέπει να αναγνωρίζουν τη διαφορετική γεωμετρική συμπεριφορά και να τη συνδέουν με τον αριθμό των λύσεων.

---

# 7. Συνεργατική δραστηριότητα ταξινόμησης

Να δημιουργηθεί μια δραστηριότητα όπου εμφανίζονται διαφορετικά γραμμικά συστήματα.

Οι μαθητές πρέπει να τα ταξινομήσουν σε:

```text
┌──────────────────┐
│ Μία λύση         │
└──────────────────┘

┌──────────────────┐
│ Καμία λύση       │
└──────────────────┘

┌──────────────────┐
│ Άπειρες λύσεις   │
└──────────────────┘
```

Η δραστηριότητα πρέπει να λειτουργεί τόσο:

* με drag & drop,
* όσο και με embodied zones.

Στο embodied mode οι τρεις περιοχές του χώρου αντιστοιχούν στις τρεις κατηγορίες.

Ο μαθητής μετακινείται στη σωστή περιοχή.

---

# 8. Μετάβαση στην Α3.3

## Αλγεβρική επίλυση

Μετά την κατανόηση της γραφικής λύσης να ακολουθεί η αλγεβρική επίλυση.

Παράδειγμα:

$$
\begin{cases}
2x+y=7\\
x-y=2
\end{cases}
$$

Οι μαθητές πρέπει να επιλέξουν κατάλληλη αλγεβρική διαδικασία.

---

# 9. Δραστηριότητα «Εξαφάνισε τον άγνωστο»

Να αναπαρασταθούν οι δύο εξισώσεις ως:

```text
2x + y = 7

 x - y = 2
```

Ο στόχος είναι οι μαθητές να αντιληφθούν ότι με την πρόσθεση των δύο εξισώσεων:

$$
(2x+y)+(x-y)=7+2
$$

προκύπτει:

$$
3x=9
$$

και επομένως:

$$
x=3
$$

Στη συνέχεια:

$$
3-y=2
$$

άρα:

$$
y=1
$$

και η λύση είναι:

$$
\boxed{(3,1)}
$$

---

# 10. Ενσώματη εκδοχή της απαλοιφής

Οι μαθητές μπορούν να αναπαριστούν φυσικά τους όρους των εξισώσεων.

Για παράδειγμα:

```text
Student A → 2x
Student B → +y
Student C → =7

Student D → x
Student E → -y
Student F → =2
```

Το σύστημα πρέπει να μπορεί να αναγνωρίζει τις ομάδες/θέσεις των μαθητών μέσω persistent ID.

Οι μαθητές πρέπει να οργανωθούν ώστε οι όροι:

```text
+y
-y
```

να «αλληλοαναιρεθούν».

Το σύστημα εμφανίζει:

$$
+y-y=0
$$

και στη συνέχεια:

$$
2x+x=7+2
$$

$$
3x=9
$$

---

# 11. Συνεργατική επίλυση

Κάθε ομάδα λαμβάνει διαφορετικό σύστημα.

Παραδείγματα:

### Σύστημα Α

$$
\begin{cases}
2x+y=8\\
x-y=1
\end{cases}
$$

### Σύστημα Β

$$
\begin{cases}
3x+2y=12\\
x-y=1
\end{cases}
$$

Οι μαθητές πρέπει να:

1. αναπαραστήσουν το σύστημα,
2. εντοπίσουν γραφικά την περιοχή/σημείο λύσης,
3. επιλέξουν αλγεβρική μέθοδο,
4. εκτελέσουν τα βήματα,
5. βρουν \(x,y\),
6. επαληθεύσουν τη λύση.

---

# 12. Τελική δραστηριότητα

Να δημιουργηθεί challenge όπου το σύστημα δίνει ένα άγνωστο σύστημα:

$$
\begin{cases}
ax+by=c\\
dx+ey=f
\end{cases}
$$

και οι μαθητές πρέπει να ολοκληρώσουν ολόκληρη τη διαδικασία:

```text
        ΣΥΣΤΗΜΑ
            ↓
     ΓΡΑΦΙΚΗ ΛΥΣΗ
            ↓
   ΠΟΣΕΣ ΛΥΣΕΙΣ;
            ↓
   ΑΛΓΕΒΡΙΚΗ ΛΥΣΗ
            ↓
      ΕΠΑΛΗΘΕΥΣΗ
```

# 15. CoordinatePlane component

Να δημιουργηθεί γενικό component:

```tsx
<CoordinatePlane
    points={points}
    lines={lines}
    students={students}
    onPointMove={handlePointMove}
/>
```

Το component να μην περιέχει ειδική λογική για γραμμικά συστήματα.

Να μπορεί να χρησιμοποιηθεί αργότερα για:

* συναρτήσεις,
* γραμμικές συναρτήσεις,
* παραβολές,
* συντεταγμένες,
* γεωμετρία,
* μετασχηματισμούς.

# 16. EmbodiedZones component

Να χρησιμοποιηθεί το ήδη σχεδιαζόμενο reusable σύστημα:

```tsx
<EmbodiedZones
    zones={zones}
    trackedStudents={students}
    onStudentEnterZone={handleZoneChange}
/>
```

Το component πρέπει να είναι ανεξάρτητο από τα μαθηματικά.

Για το συγκεκριμένο activity οι ζώνες μπορούν να είναι:

```text
ZONE_1 → Μία λύση
ZONE_2 → Καμία λύση
ZONE_3 → Άπειρες λύσεις
```

Σε άλλη δραστηριότητα οι ίδιες ζώνες μπορούν να αντιστοιχούν σε:

```text
Θετικός
Μηδέν
Αρνητικός
```

ή:

```text
Άρτιος
Περιττός
```

# 18. Σημαντική παιδαγωγική απαίτηση

Να μην περιοριστεί η δραστηριότητα στο:

> «Βρες τη σωστή απάντηση».

Το σύστημα πρέπει να καταγράφει και **τη διαδικασία**.

Για παράδειγμα:

```text
Μαθητής
   ↓
εντοπίζει γραφικά το σημείο
   ↓
επιλέγει μέθοδο
   ↓
επιλέγει πράξη απαλοιφής
   ↓
εκτελεί μετασχηματισμό
   ↓
βρίσκει x
   ↓
βρίσκει y
   ↓
επαληθεύει γραφικά
```

Έτσι η εφαρμογή μπορεί να χρησιμοποιηθεί όχι μόνο ως exercise αλλά και ως **learning analytics environment**.

# 19. Κεντρική ιδέα της δραστηριότητας

Η τελική εμπειρία του μαθητή πρέπει να συνδέει:

```text
             ΓΡΑΦΙΚΑ
                │
                ▼
         δύο ευθείες
                │
                ▼
          σημείο τομής
                │
                ▼
             ΛΥΣΗ
                │
                ▼
            ΑΛΓΕΒΡΑ
                │
                ▼
          απαλοιφή / λύση
                │
                ▼
          ΕΠΑΛΗΘΕΥΣΗ
                │
                ▼
             ΓΡΑΦΙΚΑ
```

Το embodied mode προσθέτει ένα τρίτο επίπεδο:

```text
       ΨΗΦΙΑΚΟΣ ΧΩΡΟΣ
             ↕
       ΜΑΘΗΜΑΤΙΚΟΣ ΧΩΡΟΣ
             ↕
        ΦΥΣΙΚΟΣ ΧΩΡΟΣ
```

με τους μαθητές να λειτουργούν ως **ενσώματες αναπαραστάσεις μαθηματικών αντικειμένων**.

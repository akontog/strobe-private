# Γενική Περιγραφή

Υλοποιούνται στο φάκελο client\src\shared\components.

Κανόνας περιεχομένου:
- ο κώδικας υλοποιεί μόνο rendering και interaction behavior των resources.
- δραστηριότητες, οδηγίες και μαθησιακά δεδομένα αποθηκεύονται σε JSON αρχεία.
- activity / sequence / workshop είναι επίπεδα οργάνωσης πάνω από τα resources

Resources, Widgets και Primitives είναι τα τρία επίπεδα δομικών στοιχείων της εφαρμογής, από το πιο σύνθετο στο πιο απλό.
- resources: εκπαιδευτικές δραστηριότητες/εργαλεία που βλέπει ο χρήστης ως ολοκληρωμένη ενότητα (π.χ. AlgebraTiles, GeoGebra, PlacementBoard) και μέσα τους φιλοξενούν widgets. 
- widgets: επιμέρους στοιχεία που συνθέτουν ένα resource — μικρά, αυτόνομα κομμάτια περιεχομένου όπως εξισώσεις, εικονίδια και γραφικές παραστάσεις, το καθένα υπεύθυνο για έναν συγκεκριμένο τύπο οπτικοποίησης. 
- primitives: τα πιο βασικά, γενικά δομικά στοιχεία του UI — κουμπιά, πεδία εισαγωγής, τίτλοι, αριθμητικά πλαίσια — που δεν ξέρουν τίποτα για την εκπαιδευτική λογική της εφαρμογής και μπορούν να χρησιμοποιηθούν οπουδήποτε, είτε μέσα σε widgets είτε σε layouts. 
Με λίγα λόγια: τα primitives χτίζουν τα widgets, τα widgets συνθέτουν τα resources.
- services: Εμφανίζονται κάτω από τον χώρο εργασίας σαν accordions,


Workshop, Activities και Sequences είναι τα τρία επίπεδα οργάνωσης πάνω από τα resources, ανάλογα με το πόσο ελεύθερος είναι ο χρήστης να κινηθεί. 

- activity: ένα μεμονωμένο resource — ο μαθητής ή ο δάσκαλος ασχολείται με ένα θέμα και τελειώνει εκεί, χωρίς περαιτέρω πλοήγηση. Ο author συνδυάζει ένα resource με widgets δημιουργώντας ένα json αρχείο.
- sequence είναι μια προκαθορισμένη σειρά από activities που ο εκπαιδευτικός διατρέχει γραμμικά, απλώς πατώντας «Επόμενο» και «Προηγούμενο», χωρίς να διαλέγει ο ίδιος πού θα πάει. 
- workshop: συνδυάζει πολλά resources κάτω από ένα πλούσιο μενού ή σύστημα πλοήγησης, ώστε ο δάσκαλος να μπορεί να περιηγηθεί ελεύθερα ανάμεσά τους, να επιλέξει τι θα δείξει και με ποια σειρά, και να προσαρμόσει τη ροή στην τάξη του. 

Με λίγα λόγια: το activity είναι ένα βήμα, η sequence είναι μια γραμμική πορεία βημάτων, και το workshop είναι ένας χώρος με πολλές διαδρομές που ο δάσκαλος χαράσσει ο ίδιος.

## Διάταξη (Ordering Board)

- Υλοποίηση: OrderingBoard

### Περιγραφή

Μια σειρά από αντικείμενα (αριθμοί, βήματα (κείμενο), λέξεις, εικόνες) εμφανίζονται ήδη σε μία γραμμή αλλά ανακατεμένα. Ο μαθητής σύρει και αποθέτει τα αντικείμενα μέσα στην ίδια γραμμή ώστε να τα βάλει στη σωστή σειρά. Δεν υπάρχουν πολλές σειρές/κατηγορίες — μόνο η τελική διάταξη μετράει. Η βαθμολόγηση μπορεί να είναι αυστηρή (όλη η σειρά σωστή) ή μερική (πόσα ζεύγη βρίσκονται στη σωστή σχετική θέση).

### Παράμετροι

#### rows

αριθμός γραμμών. Κάθε γραμμή έχει τα δικά της items και είναι ανεξάρτητη από τις υπόλοιπες. Ο μαθητής μπορεί να σύρει μόνο τα items της ίδιας γραμμής μεταξύ τους.

#### items

Τα αντικείμενα καθε γραμμής. Έχουν id και ακολουθεί ζεύγος με initialOrder και correctOrder για την βαθμολόγηση. Για κάθε γραμμή υπάρχει άλλο items.

## Διάγραμμα Venn

- Υλοποίηση: VennBoard

### Παράμετροι

#### sets (Αριθμός συνόλων)

Να επιτρέπεται από 1 έως 4.

#### relations (Σχέσεις)

Σχέσεις μεταξύ των συνόλων:

- disjoint (Ανεξάρτητα): Οι ελλείψεις δεν ακουμπάνε καθόλου.
- intersecting (Τεμνόμενα): Υπάρχει κοινή περιοχή.
- subset: Η μια έλλειψη βρίσκεται εξολοκλήρου μέσα στην άλλη.
Ανάλογα τον αριθμό των συνόλων θα πρέπει να υπάρχουν οι επιλογές ανά 2 σύνολα

#### Elements (στοχεία - βλέπε και OptionsGrid)

Τι θα μπορεί να επιλέξει ο δάσκαλος/μαθητής για να σύρει μέσα στα σύνολα.

## Αλγεβρικά Πλακίδια (Algebra Tiles)

- Υλοποίηση: AlgebraTiles

### Περιγραφή


| Πλακίδιο | Σχήμα | Αξία |
|---|---|---|
| Μικρό τετράγωνο | $1 \times 1$ | $1$ |
| Ορθογώνιο | $1 \times x$ | $x$ |
| Μεγάλο τετράγωνο | $x \times x$ | $x^2$ |

Για αφαίρεση κόκκινα πλακίδια.

### Παράμετροι

#### variables

Ονόματα πλακιδίων (δύο μεγεθών) π.χ. ['x', 'y'] ή ['α', 'β'] 

#### mode

- 'equation': οριζόντια γραμμή στο πάνω μέρος. Να χωράνε οι εκφράσεις πάνω από την οριζόντια και να μην μπορούν να μπουν πλακίδια. Κατακόρυφη ακριβώς στο κέντρο.
- 'system': δύο περιοχές σαν το equation ώστε να μπορούν να τοποθετηθούν τα πλακίδια
- 'area': Γραμμές που τέμνονται πάνω αριστερά αφήνοντας πάνω και αριστερά χώρο για μια γραμμή ή στήλη πλακιδίων και για την έκφραση που αυτά σχηματίζουν (σε χώρο που δεν πρέπει να μπουν πλακίδια)
- 'simplified': Καμία γραμμή, ελεύθερος χώρος για πλακίδια

### Παραδείγματα

### Η $3x + 2$ φτιάχνεται με:

- 3 ορθογώνια πλακίδια $x$
- 2 μικρά πλακίδια $1$

### Η $2x^2 - x + 4$ φτιάχνεται με:

- 2 μεγάλα θετικά $x^2$
- 1 αρνητικό $x$
- 4 θετικά $1$

### Εφαρμογές

### Ανάπτυξη (Expand)/Παραγοντοποίηση (Factor): μοντέλο του ορθογωνίου/εμβαδού

- Χρήση mode 'area'

π.χ. (x + 2)(x + 3)
  Δημιουργία ορθογωνίου με πλευρές:
    - x + 2
    - x + 3
  Γεμίζει με 
    - ένα x²
    - 3x από τη μία πλευρά
    - 2x από την άλλη
    - 6 μονάδες
   Άρα: $(x + 2)(x + 3) = x^2 + 5x + 6$
```
                              x + 3  (πλάτος)
                  ┌──────┬────┬────┬────┐
                  │  x   │ 1  │ 1  │ 1  │
            ┌─────┼──────┼────┼────┼────┤
            │  x  │  x²  │ x  │ x  │ x  │
            ├─────┼──────┼────┼────┼────┤
    x + 2   │  1  │  x   │ 1  │ 1  │ 1  │
    (ύψος)  ├─────┼──────┼────┼────┼────┤
            │  1  │  x   │ 1  │ 1  │ 1  │
            └─────┴──────┴────┴────┴────┘
```
#### Εξισώσεις
- Χρήση mode 'equation'

#### Συστήματα
- Χρήση mode 'system'

## Αριθμογραμμή (Number Line)

- Υλοποίηση: NumberLine

Κάθε συμμέτοχος μπορεί να βάλει ένα σημείο (με το χρώμα χρήστη που έχει επιλέξει) πάνω στην αριθμογραμμή.
Κατακόρυφες αχνές γραμμές στις οποίες υπάρχει και ένα μικρό snapping
Θα πρέπει ο χρήστης να μπορεί να σχεδιάσει είτε μεμονωμένα σημεια είτε διαστήματα (ανοιχτά κλειστά).
Αν 2 ή παραπάνω συμμετέχοντες επιλέξουν το ίδιο σημείο είτε το ίδιο διάστημα στην αριθμογραμμή, για να φαίνεται αυτή, θα τοποθετείται λίγο παραπάνω στην κατακόρυφη; Να το σκεφτώ.

## Καρτεσιανό Επίπεδο (Cartesian Plane)

- Υλοποίηση: CartesianPlane
Μπορεί να περιέχει ήδη κάποιο απλό σχέδιο (σημεία ή τμήματα/ημιευθείες/ευθείες). Μπορεί π.χ. να επιτρέπει τον μαθητή να φτιάξει μόνο ένα σημείο αλλά αυτό να ενώνεται με κάποιο άλλο σταθερό σημείο δημιουργώντας τμήμα ή ευθεία. Δοκίμασε το σε δραστηριότητα 1.1 στη γεωμετρία (μετατόπισε τις υπόλοιπες δραστηριότητες μια θέση μετά.). Σε αυτή υα υπάρχει ήδη μια ημιευθεία που ξεκινά από ένα σημείο Α και ο μαθητής θα μπορεί να κάνει κάπου click δημιουργώντας άλλη μια ημιευθεία παό το Α που περνάει από το σημείο δημιουργώντας γωνία.

Τέλεια! Τώρα θέλω σαν 1.3 (μετέφερε από 1.3 και μετά μια θέση μπροστά) μια δραστηριότητα, πάλι σε CartesianPlane όπου θα υπάρχει ένα ευθ. τμήμα και θα πρέπει ο μαθητής να κάνει click σε ένα σημείο ώστε να σχηματίσει ένα Οξυγώνιο, αμβλιγώνιο, ορθογώνιο. Πάλι θα μοιράζεται τυχαία η ανάθεση στους μαθητές

Για 1.6 θέλω ένα συνεργατικό GeoGebra όπου θα υπάρχει ήδη ένα σκαληνό τρίγωνο όπου οι μαθητές θα χρησιμοποιήσουν το geogebra για να βρουν μέσο απέναντι πλευράς ή να τραβήξουν κάθετο. 
### Παράμετροι

#### mode

Πίνακας που να μπορεί να περιέχει 1 ή παραπάνω
- 'lines'
- 'points'
Όταν περιέχει και lines και points με drag and drop ευθείες με click σημεία

## Embodied / Camera

### Περιγραφή

- 1 κάμερα, μόνο στον teacher
- Ο Server επιστρέφει τα σημεία τα οποία κάνει tracking πίσω στον teacher αλλά και στους students που θα βλέπουν τα σημεία. 
- Ο κάθε student με το ποντίκι μπορεί να κουνήσει μόνο το δικό του σημείο. 
- Ανάλογα με το activity που έχει επιλεγεί από τον teacher Θα βλέπει και τα σταθερά σχήματα του activity

Χρήση camera tracking και persistent ID.

Οι μαθητές μπορούν να:

* μετακινούνται στον χώρο,
* σχηματίζουν ομάδες,
* μπαίνουν σε χωρικές ζώνες,
* αναπαριστούν μαθηματικά αντικείμενα.

Το σύστημα πρέπει να γνωρίζει:

- studentId
- x
- y
- zoneId
- timestamp

# Εξισώσεις δεύτερου βαθμού με πλακίδια

Μια εξίσωση δεύτερου βαθμού έχει μορφή ax² + bx + c = 0, με a ≠ 0. Τα πλακίδια x², x και μονάδας αναπαριστούν τους αντίστοιχους όρους.

Για να διατηρείται η ισότητα, κάθε μεταβολή στο ένα μέλος πρέπει να γίνεται και στο άλλο. Ζεύγη ίσων πλακιδίων με αντίθετα πρόσημα αλληλοαναιρούνται.

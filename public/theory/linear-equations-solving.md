# Επίλυση απλών εξισώσεων

Στόχος είναι να απομονώσουμε τον άγνωστο x.

Κάνουμε την ίδια πράξη και στα δύο μέλη, ώστε να διατηρείται η ισότητα. Μεταφέρουμε πρώτα τους σταθερούς όρους και στη συνέχεια διαιρούμε με τον συντελεστή του x.

Παράδειγμα: x + 3 = 5 ⇒ x = 5 − 3 ⇒ x = 2. Ελέγχουμε τη λύση αντικαθιστώντας την στην αρχική εξίσωση.

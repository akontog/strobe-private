# Linear Seperation Tool

React εργαλείο για έλεγχο γραμμικού διαχωρισμού (target-vs-rest) από JSON τύπου `datasets.js`.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Input

- Επικόλληση JSON στο textarea
- Ή upload `.json` αρχείου

Το εργαλείο:
- επιλέγει dataset
- επιλέγει target κατηγορία
- αναζητά ακέραιο υπερεπίπεδο `w·x > θ`
- εμφανίζει επαλήθευση για όλα τα παραδείγματα
